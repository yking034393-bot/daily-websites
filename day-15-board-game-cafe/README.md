# Dice & Dragons — Board Game Café (Day 15)

A board game café website with a filterable, searchable game library
(14 games across strategy, party, co-operative, family, card and classic
categories, filterable by player count and sortable by time or difficulty),
a game reservation basket with £2 rental per game, a café menu, six weekly
events (including D&D night and Friday tournaments), a live opening-hours
indicator, and a table booking form.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — game catalogue filtering/search/sorting, basket, reservations, table booking, opening-hours indicator

## Run it

Open `index.html` in any browser. No build step or server needed.
