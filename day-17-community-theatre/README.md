# Day 17 — The Velvet Stage Community Theatre

A community theatre website for a volunteer-run local theatre.

## Features

- **Season catalogue** — six productions (Macbeth, a Cinderella pantomime, The Importance of Being Earnest, a spring musical, a whodunit homage, and an improv night), searchable by title and filterable by genre (drama, comedy, musical, family).
- **Ticket booking** — pick a performance date, choose adult / concession / under-18 quantities with live pricing, and add to a ticket basket.
- **Basket drawer** — review reserved tickets, remove items, and reserve with a generated reference number (pay on collection at the box office).
- **Plan your visit** — address and access info, ticket price list, and a live open/closed indicator based on the current day and time.
- **Get involved** — audition registration, volunteer sign-up, and a newsletter form with confirmation messages.
- **About** — the theatre's story and production statistics.

## Run it

Open `index.html` in any browser. No build step or server needed.
