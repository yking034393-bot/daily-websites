# Day 02 — Green Thumb Nursery

A plant nursery / garden centre website: hero, filterable plant shop (12 plants,
filter by low light / bright light / pet friendly), an "Add to basket" basket
counter with toast notifications, a plant-care guide, visit info, and a
newsletter signup.

## Files

- `index.html` — page structure
- `styles.css` — styling (green/cream nursery theme, responsive)
- `script.js` — plant catalogue, filtering, basket counter, newsletter form

## Run it

Open `index.html` in any browser — no build step needed.
