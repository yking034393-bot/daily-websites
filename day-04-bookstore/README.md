# Day 04 — The Story Nook (Independent Bookstore)

**Date:** 2026-11-08
**Topic:** Independent bookstore

A cosy independent bookstore website for "The Story Nook", a fictional neighbourhood bookshop on Lantern Lane.

## What's inside

- **Hero** with a staff pick of the month and opening-hours note
- **Features** — free local delivery, gift wrapping, buy-back shelf, reading nook
- **Book catalogue** — 16 books across fiction, mystery, children's, non-fiction, and poetry, with live search (title/author) and genre filters
- **Basket** — add books, with a basket counter and summary toast
- **Events** — author evening, Saturday storytime, poetry open mic, with RSVP buttons
- **Book clubs** — three clubs with a working sign-up form
- **Visit us** — address, opening hours, and a newsletter sign-up form

## Files

- `index.html` — page structure
- `styles.css` — warm, bookish styling (cream paper, rust accent, green)
- `script.js` — catalogue data, search/filter, basket, forms, and toasts

## Run it

Open `index.html` in any browser. No build step or server needed.
