# Fern & Fable — Florist & Flower Studio (Day 14)

A neighbourhood florist website with a filterable, searchable bouquet catalogue
(12 arrangements across bouquets, roses, seasonal and potted), a basket with
collection reservation, a live opening-hours indicator, occasion guides
(birthdays, weddings, sympathy, just because), three weekly flower
subscription plans, flower care tips, and a delivery booking form.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — catalogue filtering/search/sorting, basket, subscriptions, delivery booking, opening-hours indicator

## Run it

Open `index.html` in any browser. No build step or server needed.
