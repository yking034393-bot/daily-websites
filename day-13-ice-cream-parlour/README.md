# Day 13 — The Golden Scoop Ice Cream Parlour

An artisan ice cream parlour website for a small-batch scoop shop in Brighton.

## What's inside

- **Hero** — animated ice-cream cone, floating flavour chips, and key stats
- **Flavours** — 16 flavours with category filters (Classics, Fruit & Sorbet, Chocolate, Vegan) and live search
- **Build Your Own Sundae** — pick a size, up to 3 scoops, and toppings with a live price total, then add it to the basket
- **Basket** — slide-in drawer with add/remove, running total, and collection reservation
- **Visit Us** — address, opening hours, and a live "open now" indicator based on the time of day
- **Parties & Scoop Socials** — booking request form with confirmation message
- **Scoop List** — monthly newsletter sign-up
- **Rotating specials ticker** — a new special every few seconds

## Files

- `index.html` — page structure
- `styles.css` — cream/pink/chocolate styling, responsive layout
- `script.js` — flavour data, filters, search, sundae builder, basket, opening hours, forms

## Run it

Open `index.html` in any browser — no build step or server needed.
