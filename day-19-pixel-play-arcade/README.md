# Day 19 — Pixel Play Arcade (Gaming Website)

A gaming arcade website built with **HTML, CSS and JavaScript** — no frameworks, no build step.

## What's inside

- **Hero** — animated impact stats (games, rigs, players, prizes)
- **Game catalogue** — 9 games across 5 genres, with live search and genre filters (HTML + JS)
- **Playable Snake game** — a real canvas mini-game with arrow-key and on-screen controls, live score and a saved best score (JavaScript + localStorage)
- **Leaderboard** — top 5 weekly scores, plus a form to add your own Snake score
- **Tournaments** — 3 upcoming events with one-click seat booking
- **Membership** — Day Pass, Monthly Pro and Squad plans with plan selection
- **Live open/closed indicator** — reads the real clock (open 11:00 AM – 1:00 AM)
- **Newsletter form** with confirmation message

## Files

- `index.html` — page structure
- `styles.css` — all styling (dark neon arcade theme)
- `script.js` — catalogue filtering, Snake game, leaderboard, bookings, forms
