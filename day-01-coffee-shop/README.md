# Day 01 — Brew & Bean Coffee House

**Date:** 2026-11-05

A modern coffee shop website with a clickable menu, a live order total, about/roasting info, hours, and a contact form.

## Files

- `index.html` — page structure
- `styles.css` — styling, responsive layout
- `script.js` — menu rendering, order total, contact form

## Run it

Open `index.html` in a browser, or serve the folder with any static server.
