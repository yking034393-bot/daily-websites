# Day 03 — Harmony Yoga Studio

A calm, welcoming website for a small yoga studio.

## Features

- Hero section with a featured class and one-click reservation
- Filterable class catalogue (8 classes across beginner, intermediate, advanced and restorative)
- Interactive weekly schedule with day tabs and per-class spot counts
- Teacher profiles
- Three pricing plans with a featured Monthly Unlimited option
- Booking form with confirmation message (first class free)

## Files

- `index.html` — page structure
- `styles.css` — warm sage/cream styling, responsive layout
- `script.js` — class filtering, schedule tabs, booking and plan selection

## Run it

Open `index.html` in any browser, or serve the folder with any static server.
