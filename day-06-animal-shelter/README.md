# Day 06 — Paws & Whiskers Animal Shelter

**Date:** 2026-11-10
**Topic:** Animal shelter & pet adoption website

## What it is

A warm, friendly website for a no-kill animal shelter, helping visitors find
and adopt their new best friend.

## Features

- **Adoptable pets catalogue** — 12 pets (dogs, cats, and rabbits) with
  photos (emoji), breed, age, size, personality notes, and adoption fee.
- **Filters** — filter by species, age group, and size, plus live search by
  name or breed, with a live results count.
- **Adopt buttons** — starting an application shows a friendly confirmation
  and next steps.
- **How Adoption Works** — a 3-step guide (meet, apply, take them home) with
  fee notes.
- **Volunteer sign-up** — form with role selection and a confirmation message.
- **Events** — adoption day, photo fundraiser, and winter donation drive.
- **Donate section** — quick-pick amounts ($10 / $25 / $50 / $100) with a
  thank-you message.
- **Newsletter sign-up** in the footer.
- **Responsive design** — mobile menu, stacked layouts on small screens.

## Files

- `index.html` — page structure and content
- `styles.css` — warm cream/orange/green styling
- `script.js` — pet data, filtering, forms, and interactions

## Run it

Open `index.html` in any browser — no build step or server needed.
