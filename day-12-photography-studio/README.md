# Day 12 — Lens & Light Photography Studio

**Date:** 2026-11-16
**Topic:** Photography studio
**Folder:** `day-12-photography-studio/`

## What it is

A photography studio website for "Lens & Light" — portraits, weddings, landscapes and events.

## Features

- Hero section with studio stats (240+ weddings, 1,800+ portrait sessions)
- Filterable portfolio gallery (12 photos across Portraits, Weddings, Landscapes, Events) with a lightbox preview
- Services & pricing: Portrait Session ($180), Wedding (from $1,450), Family Session ($240), Event Coverage ($95/hour)
- Photographer profiles (Ana Reyes, Daniel Kim, Sofia Patel)
- Client testimonials
- Booking form with validation and a confirmation message
- "Photo of the Month" newsletter sign-up
- Responsive layout with a mobile menu

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — gallery filtering, lightbox, services, booking and newsletter forms

## How to view

Open `index.html` in a browser, or serve the folder with any static server.
