# Day 08 — The Golden Whisk Artisan Bakery

**Date:** 2026-11-12
**Topic:** Artisan bakery website

## What it is

A warm, crusty website for a small neighbourhood artisan bakery, helping
visitors shop today's bakes, check when bread comes out of the oven, order
a custom cake, and plan a visit.

## Features

- **Today's Bakery** — 12 fresh bakes (breads, pastries, sweet bakes, vegan)
  with live search, category filters, and price/name sorting.
- **Basket** — slide-in drawer with quantities, running total, and a
  reservation code for in-store collection.
- **Out of the oven now** — hero card showing the current fresh batches.
- **Daily Bread Schedule** — when each loaf is baked and when it usually
  sells out.
- **Custom Cakes** — 4 signature cakes plus a request form (occasion,
  flavour, servings, collection date with no past dates) and confirmation.
- **Our Story** — the bakery's story, key stats, and a 5-step "How a loaf
  is made" guide.
- **Visit** — address, hours, and a daily bake-list newsletter sign-up.
- **Responsive design** — mobile menu, stacked layouts on small screens.

## Files

- `index.html` — page structure and content
- `styles.css` — warm cream/crust/gold bakery styling
- `script.js` — bake data, filters, basket, schedule, and forms

## Run it

Open `index.html` in any browser — no build step or server needed.
