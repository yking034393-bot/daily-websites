# Day 07 — Riverstone Pottery Studio

**Date:** 2026-11-11
**Topic:** Pottery / ceramics studio website

## What it is

A warm, earthy website for a handmade ceramics studio, helping visitors
discover classes, buy one-of-a-kind pottery, and visit the riverside studio.

## Features

- **Classes catalogue** — 9 classes (beginner to advanced, plus kids & families)
  with schedule, price, and level filters.
- **Book this class** — jumps to the booking form with the class pre-selected.
- **Shop** — 8 handmade pieces with live search, price/name sorting, and a
  working basket with quantities, totals, and a demo checkout message.
- **Gallery** — 6 kiln-fresh pieces with a click-to-open lightbox (keyboard
  accessible, closes with Escape).
- **The Studio** — open studio nights, glazing bar, private parties, kiln
  firing service, plus a 6-step "How a piece is made" guide.
- **Booking form** — class, date (no past dates), party size, with a
  confirmation message.
- **Newsletter sign-up** in the Visit section, with address, hours, and contact.
- **Responsive design** — mobile menu, stacked layouts on small screens.

## Files

- `index.html` — page structure and content
- `styles.css` — warm clay/terracotta/sage styling
- `script.js` — class data, shop, basket, gallery, and forms

## Run it

Open `index.html` in any browser — no build step or server needed.
