# Day 16 — Spin & Groove Records (Vinyl Record Store)

A vinyl record store website with a searchable, filterable record catalogue
(genre, format, price/year sorting), a basket with collection reservation,
new arrivals, turntables and care gear, listening-night events, a live
opening-hours indicator, a sell-your-records section, and newsletter sign-up.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — catalogue data, filtering, basket, opening-hours logic

## Run it

Open `index.html` in a browser. No build step needed.
