# Day 11 — The Sharp Cut Barbershop

A barbershop website for "The Sharp Cut" — classic cuts, hot towel shaves, beard sculpting and kids' cuts.

## Features

- Hero with shop stats (rating, years in business, average appointment time)
- Services & prices with category filters (Hair, Beard, Shave, Kids)
- "Book this" buttons on every service that pre-fill the booking form
- Meet the Barbers section with specialties
- Gallery of styles — tapping a style pre-selects it in the booking form
- Customer reviews
- Booking form with validation and confirmation message (name, phone, service, barber, date, time)
- Hours, location, and newsletter sign-up with 10% off first-cut offer
- Responsive layout with a mobile navigation menu

## Files

- `index.html` — page structure
- `styles.css` — styling
- `script.js` — filters, booking, newsletter and mobile nav

## Run it

Open `index.html` in any browser. No build step needed.
