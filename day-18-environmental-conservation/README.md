# Day 18 — Verdant Earth (Environmental Conservation)

An environmental conservation organisation website.

## Features

- **Impact stats** — animated counters for trees planted, CO₂ offset, volunteers and habitats restored.
- **Projects catalogue** — nine real-feeling conservation projects (Margalla Hills reforestation, Indus Delta mangroves, coral revival, snow leopard guardians, solar schools and more), searchable and filterable by forests, oceans, wildlife and climate, each with a funding progress bar.
- **Carbon footprint calculator** — sliders for flights and car travel plus home energy use, estimating yearly CO₂ in tonnes and how many trees would balance it.
- **Donations** — preset and custom amounts with a live impact preview (trees planted, ocean plastic cleared) and one-time/monthly choice, with a confirmation message.
- **Volunteer sign-up** — name, email, interest and city, with a personalised confirmation.
- **Events** — tree planting day, beach clean-up and wetland bird survey, each with a reserve-a-spot button.
- **Newsletter** — monthly updates sign-up with confirmation.

## Run it

Open `index.html` in any browser. No build step or server needed.
