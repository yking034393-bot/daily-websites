# Day 10 — Sunset Surf School

A surf school website for Sunset Beach: learn to ride the waves, one sunset at a time.

## Features

- **Surf conditions card** in the hero — today's wave height, water temperature, wind, and best session times.
- **Filterable lesson catalogue** — 9 lessons filterable by level (beginner, intermediate, advanced, kids, private) with live search.
- **Board & gear rentals** — 9 rental items filterable by type (surfboards, wetsuits, accessories).
- **Basket** — add lessons and rentals, adjust quantities, and check out with a demo confirmation.
- **Weekly schedule** — group lessons every day from Dawn Patrol (7am) to the Sunset Session (5:30pm).
- **Instructors** — profiles of the three lead instructors.
- **Pricing** — single lesson, Surf Week, and Season Pass.
- **Lesson booking form** — pick a lesson, date, time, and group size; confirmation message on submit.
- **Visit info** — location, hours, and contact details.
- Responsive layout with a mobile menu.

## Files

- `index.html` — page structure and content
- `styles.css` — styling (ocean blue, coral, sand palette)
- `script.js` — lesson/rental data, filtering, search, basket, booking form
- `README.md` — this file

Open `index.html` in a browser to view the site.
